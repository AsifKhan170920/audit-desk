# Kazabooks for Windows and Mac

A window around https://kazabooks.com with every app of the business (Accounting, Kaza Limousine, CRM,
Audit Desk). The source of truth is `Documents\kazabooks\desktop`; this copy is here so GitHub can build
the Mac app (it can only be built on a Mac) – see `.github/workflows/kazabooks-mac.yml`.

Downloads: https://github.com/AsifKhan170920/audit-desk/releases/tag/kazabooks-mac
